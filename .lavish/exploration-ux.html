Product direction

Let people explore first. Turn understanding into structure later.

The primary object should not be a lesson plan or an isolated chat. It should be an exploration space: a durable web of conversations, questions, definitions, claims, sources, and eventual learning paths.

Three jobs, one workspace

Default

Explore

Follow curiosity, ask rough questions, compare interpretations, and branch without committing to a curriculum.

On demand

Verify

Turn a model statement into an explicit claim, attach evidence, record uncertainty, and preserve disagreement.

When ready

Learn

Promote a mature cluster of ideas into objectives, lessons, retrieval checks, and tracked mastery.

  C -- Yes --> D["Branch from message or selection"]
  D --> E["Explore, define, or verify"]
  E --> F["Capture conclusion as an insight"]

  G --> B
  F --> H{"Cluster is mature?"}
  H -- Not yet --> I["Keep as knowledge graph"]
  H -- Yes --> J["Promote into a learning plan"]

Branch context should be explicit

Let the user choose selection only, recent exchange, or full parent summary. Show the inherited material in the side panel so hidden context never feels magical.

Graph nodes should be meaningful

Graph threads, concepts, claims, sources, and insights—not every message. Otherwise the graph becomes an impressive but unusable hairball.

Branches need a return path

A side conversation is incomplete until its conclusion can be summarized, linked, and brought back into the parent without copying an entire transcript.

A disciplined MVP sequence

Thread branching

Branch from a whole message or selected text. Store parent thread, source message, selected excerpt, and inherited context snapshot.

Tree navigation before graph navigation

Add a dependable thread sidebar, breadcrumbs, origin preview, and “return to parent.” The tree is the operational interface.

Insight promotion

End a branch with “capture conclusion” and “send to parent.” Insights are durable objects with backlinks to evidence.

Claim verification

Mark claims unverified, supported, disputed, or superseded. Attach sources and preserve which conversation asserted what.

Graph and lesson promotion

Visualize meaningful objects and let the user select a cluster to turn into a learning plan. Keep this downstream of useful branching.

The key product decision

Should TeachMe feel primarily like a conversation app that grows structure, or a knowledge graph where conversations happen inside nodes? I recommend the former: conversation is familiar, while structure appears progressively as the user branches, saves, and verifies.
